# Full House: AI Research Paper

This repository contains my AP Research paper, completed during my junior year of high school. The project explores AI bluffing behavior in modified Leduc Poker by comparing a custom AI model with human players.

## Project Overview

For this project, I:

- Built an AI poker agent
- Designed and conducted an experiment with human participants
- Collected and analyzed gameplay data
- Compared bluff frequency, betting patterns, confidence, and win rates
- Evaluated how AI makes strategic decisions under uncertainty

## Tools Used

- Python
- JavaScript
- Node.js
- OpenAI API
- Statistical analysis
